#Example Project Description
#Project Name: Bulk Sphere 

A simple example script for nucleating a water droplet in bulk with accompanying post-processing calculations to compute
an averaged isosurface. Simply run the script bulk_sphere.sh (after installing using cmake) to generate the data and perform 
the analysis. The final output will be a sequence of stl files showing instantaneous interfaces for spherical 
droplets, and a final mesh will correspond to the marching cubes output of the average density field.
